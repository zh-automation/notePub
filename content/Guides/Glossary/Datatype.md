## Datatype
This is a descriptor for how a value is organized in a programming language. For instance, if you want a variable that can handle only a true or false value, you would use a [[Boolean]] datatype. 
A datatype is, often, a class within the programming language designed to handle specific types of data based on the size and how it is interpreted. So, in C an int datatype is a whole number   For instance, a bool datatype in python is defined as [this](https://github.com/python/cpython/blob/main/Objects/boolobject.c).
